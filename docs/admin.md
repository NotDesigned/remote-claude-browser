# 管理

> 读者：工作台管理员

管理员从右上角的「⋯」菜单进入「管理后台」，下设「用户」「会话」「资源」三个页签。管理员还维护共享的代理来源和共享 CPA 实例，分配收件地址，批准出口主机。普通用户能做的事见[使用](usage.md)；服务器、数据卷和备份由部署者管理，见[部署](deployment.md)。

管理员不能直接打开其他用户的浏览器配置，也不能进入其他用户的私有 CPA 实例。私有代理来源是例外：管理员可以查看、使用和管理所有用户的私有来源。

## 用户

「用户」页签列出每个用户的权限、状态（「在线」「离线」「已停用」）、配置数和会话数，通过单点登录登录过的用户还标有「单点登录」和对应的邮箱。

- **新建**：点「新建用户」，填写用户名、「初始密码」和「权限」（「普通用户」或「管理员」），点「创建用户」。密码至少 8 个字符。
- **编辑**：选中用户，可以改用户名、权限、「会话上限（留空不限）」，或填写「新密码（留空则保持）」重置密码，点「保存更改」。
- 重置密码、修改权限、停用和删除都会撤销这个用户在所有设备上的工作台登录，并删除他的全部 remote-cc 令牌（电脑需要重新批准）。浏览器配置和网站登录资料保留。
- 「查看此用户的会话」跳到「会话」页签并按这个用户筛选。

### 会话上限

「会话上限（留空不限）」限制一个用户登记的会话数，包括在线和休眠的会话。留空表示不限，`0` 表示禁止新建。降低上限不会结束已有会话，已有会话重连不占新名额。离线会话仍占名额，结束它会释放名额。服务端整体的内存准入和其他上限见[部署 · 资源与超时](deployment.md#资源与超时)。

### 停用和删除用户

- **停用**：取消勾选「启用账号」后「保存更改」。立即结束这个用户的所有浏览器会话，停止他的私有 CPA 实例，他的调用 Key 无法继续调用。浏览器配置、网站登录资料、CPA 授权凭据和调用 Key 的记录都保留。重新启用后，用户需要重新登录，共享实例的调用 Key 恢复可用，私有 CPA 实例要手动启动。
- **删除**：「删除用户与数据」永久删除这个用户的浏览器配置和网站登录资料、私有代理来源、私有 CPA 实例（容器和数据卷）、全部调用 Key 和单点登录的绑定。共享资源和其他用户不受影响。清理失败时用户保持停用状态，可以再次删除。需要保留资料时用停用。
- 最后一个启用的管理员不能被停用、降级或删除；管理员不能删除自己，要由另一个管理员删除。
- 数据的备份由部署者另行管理，删除后不能从工作台恢复。

### 单点登录的用户

部署者启用单点登录后（见[环境变量 · 单点登录](configuration.md#单点登录oidc)）：

- 第一次用单点登录的人会自动得到一个「普通用户」，用户名取自身份提供方的用户名或邮箱，重名时加数字。这样创建的用户没有本地密码，需要用户名和密码登录时，给他设置一个「新密码」。
- 部署者设置了管理员组时，通过单点登录创建的用户每次登录都按是否在这个组里调整为「管理员」或「普通用户」；自己绑定单点登录的已有用户不受影响。最后一个管理员不会因此被降级。
- 在身份提供方移除某人只会阻止他下次登录；他已经登录的工作台会话要到登录有效期结束才失效。要立即切断访问，在这里停用他。
- 删除一个通过单点登录创建的用户后，只要身份提供方仍放行，此人下次登录会得到一个新的空用户。要阻止他再进来，停用而不是删除。
- 没有本地密码的用户长时间不用单点登录时，他批准的 remote-cc 电脑和出口主机都会暂停使用，登录一次工作台即可恢复。批准出口主机的管理员最好有本地密码。期限见[环境变量 · 单点登录](configuration.md#单点登录oidc)。

## 会话

「会话」页签列出所有用户的会话：所属用户、配置名称、「在线」或「离线」、「页面运行中」或「已休眠」和创建时间，可以按「所属用户」筛选。「结束会话」关闭其中的远程页面并释放名额，浏览器登录资料保留。

## 资源

「资源」页签显示服务内存、整机内存、整机 CPU、运行中的浏览器、运行中的会话、全部会话和在线设备，每 5 秒更新。普通用户看不到这些数字，只在内存紧张时从顶栏的「连接」面板看到提示。内存紧张时新建和恢复会话会被暂缓，已有会话不受影响。

## 共享资源

- **共享代理来源**：在「网络与接入」→「代理来源」导入时把「可见范围」设为「共享」，所有用户都能用其中的节点，只有管理员能修改。修改或删除共享来源会影响所有绑定了这些节点的浏览器配置和 CPA 授权。
- **共享 CPA 实例**：在「网络与接入」→「CPA 授权与 Key」点「创建共享 CPA 实例」。共享实例的启动、停止、Claude 授权和凭据只由管理员管理，原生管理页面也只有管理员能进入。所有启用的用户都能为共享实例生成和撤销自己的调用 Key；管理员能看到每个共享调用 Key 的所有者，并撤销任意一个。

### 收件地址

收件域名由部署者配置（见[部署 · 收件箱](deployment.md#收件箱)），用户可以在任一已启用的域名下新建地址，`inbox-` 开头的地址名留给工作台自建的地址。

管理员可以把一个已有地址分配给指定用户：在「用户」页签选中他，在「收件地址」一节填写「已有邮箱地址」，点「分配地址」。分配后开始收录新邮件，管理员能看到分配了哪些地址，但邮件只有这个用户能读。已经分配过、或删除后停用的地址不能再分配。删除用户时他的收件地址一起删除。

## 出口主机

remote-cc 的出口主机在 remote-cc 服务器上为 remote-cc 会话提供出网，部署方法见 remote-cc 的[出口主机的部署](https://github.com/NotDesigned/remote-cc/blob/main/deploy/README.md#egress-host)。安装时它会显示一个连接码和链接，只能由管理员批准：

1. 打开链接，或在「网络与接入」→「remote-cc」的「批准连接」里输入连接码，核对后点「查看」。
2. 确认来源 IP 和发起时间，点「批准」。

**批准后，这台出口主机可以为会话取得节点的完整配置，包括节点凭据。只批准你自己的、信任的服务器。**它的运营者能看到在上面运行过会话的用户的节点凭据。

批准过的出口主机列在「出口主机」里，点「断开」立即让它失效。出口主机的令牌属于批准它的管理员：这个管理员被降级、停用或删除时，令牌随之失效，需要另一个管理员重新批准。令牌的权限和撤销的效果见[接口契约](remote-cc.md#tokens)。
