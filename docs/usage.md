# 使用

> 读者：使用工作台的人

Remote Claude Browser（RCB）的工作台在服务器上为你运行真实的 Chromium。网页的脚本、Cookie 和网络请求都留在服务器上，你在自己的浏览器里查看和操作。你的设备不需要安装任何东西，打开部署者给你的地址（例如 `https://browser.example.com`）即可。

右上角的「⋯」菜单通向各个页面：「浏览器配置」「网络与接入」「收件箱」「我的账号」，管理员还有「管理后台」（见[管理](admin.md)）；下面是画面清晰度、外观、外部链接、网页通知这些设置，最底下是当前用户和「退出登录」。配置选择页右上角也有同一个菜单。「网络与接入」面板有「代理来源」「CPA 授权与 Key」「remote-cc」三个页签，打开时停在上次用的页签。

## 登录

用管理员给你的用户名和密码登录。部署者启用了单点登录时，登录页的用户名和密码下方还有一个单点登录按钮（文字由部署者设置，默认是「使用单点登录」），点它在你的身份提供方登录即可：

- 第一次用单点登录时，工作台会为你新建一个用户。这样创建的用户没有本地密码，只能用单点登录进入；需要用户名和密码时，请管理员为你设置密码。
- 已经有用户名和密码的，可以在「我的账号」→「单点登录」点「绑定单点登录账号」，之后两种方式都登录到同一个用户。一个单点登录账号只能绑定一个用户。

登录的有效期见[部署 · 资源与超时](deployment.md#资源与超时)。

### 我的账号

「我的账号」里可以：

- 在「我的浏览器会话」里查看并结束自己在各个设备上的会话。结束会话会关闭其中的网页，但不会退出网站账号。
- 「修改密码」。修改后所有设备都要重新登录工作台，浏览器里的网站登录不变。当前密码输错后要稍等片刻才能再试，连续输错等待会变长，和登录页一样。
- 在「单点登录」一节查看或绑定单点登录账号（部署者启用了单点登录时才显示）。

工作台的用户和你在网站上的账号无关：新用户的浏览器配置里没有任何网站登录，你自己决定登录哪些网站。

## 浏览器配置

浏览器配置是一套独立的浏览器：有自己的 Chrome 进程、网站登录资料、出口、屏幕尺寸和字体。同一个配置可以同时开多个会话（不同设备或窗口），它们共享网站登录；不同配置互相独立。每个用户能保存的配置数有上限，见[部署 · 资源与超时](deployment.md#资源与超时)。

登录后先看到配置选择页。卡片上显示 Claude 的登录邮箱和登录状态，以及配置是否「运行中」或「休眠」。

- **新建**：点「新建浏览器配置」，填写名称，选择出口（没有可用节点时先「导入节点或订阅」），再点「检查并打开」。出口检查不通过时不会创建配置，表单保留；配置已创建但浏览器没打开时，可以在列表里重试。
- **打开**：点卡片打开这个配置。正在使用一个会话时，可以从「⋯」→「浏览器配置」回到选择页切换配置，或点「返回会话」。
- **卡片的「⋯」菜单**：「设置出口」「设置系统」「检查出口」「查看详情」「在 remote-cc 中使用」「重命名」「设为默认」「删除」。默认配置不能删除；删除会清除这个配置的网站登录和浏览数据，不能恢复。

## 页面模式和画面模式

顶栏的「页面」「画面」在两种查看方式之间切换，两者用的是服务器上同一个会话：

- **页面模式**：日常使用。你收到的是重建后的无脚本页面，文字清晰，可以选择、复制和查找，占用带宽少。
- **画面模式**：直接查看和操作远程浏览器的实时画面，用于登录、验证码和页面模式显示不全的页面。远程浏览器不会弹出保存密码、翻译、通知授权这类它自己的提示框，网站的登录照常保留。

两种模式都可以用本机的中文输入法：在画面模式里先点远程页面的输入框，再切换输入法，候选窗口显示在本机。页面模式在电脑上会跟随远程页面的光标：远程页面自己把光标放进输入框时（例如打开页面或发送消息之后），本机也聚焦同一个输入框，可以直接用输入法打字；手机上不会因此自动弹出键盘。声音和麦克风都在你自己的设备上。

顶栏右侧的状态（「已连接」「同步中」「输入未同步」「连接中」「重新连接中」）可以点开，打开「连接」面板：

- 当前状态和原因，例如「输入未同步」表示最近一次输入没有同步到页面，回车暂时不会发送，会自动重试，也可以点「重新同步」。
- 延迟和速度；画面模式下还有帧率。
- 断线时有「重新连接」，立即重试，不必等自动重连。
- 服务器内存紧张时这里会提示，新建会话可能失败，已打开的会话不受影响；有提醒时状态旁会出现一个小圆点。
- 「出口」：当前配置的出口位置、当地日期时间和时区。宽屏时顶栏也显示出口城市和当地时间。
- 「诊断」：默认收起，展开后是网络往返 RTT、回放缓冲、最高速度、各阶段帧率、页面重新同步次数和每个标签页的模式。页面频繁重新同步时，面板会提示画面可能短暂停顿。

顶栏的「更多」菜单只放设置：

- 「画面清晰度」：「流畅」「均衡」「清晰」，越清晰，服务器负担越重。
- 「外观」：「跟随系统」「浅色」「深色」。
- 「页面里的外部链接」：在远程浏览器的「内部标签」里打开，或用「本机浏览器」打开。
- 「网页通知」：「开启」或「关闭」，见[网页通知](#网页通知)。

在线设备、会话数、CPU 和内存这类整台服务器的数字只有管理员能在「管理后台」的「资源」页签里看到。

其他行为：

- **文件**：可以上传本机文件、下载远程浏览器里的文件，大小上限显示在上传界面上。
- **断线和刷新**：浏览器标签页切到后台会断开连接，切回来自动重连；刷新页面或断线后回到原来的会话。所有设备都断开一段时间后，远程页面会关闭以释放内存，下次打开时重新载入网址，未发送的草稿不保留（时长见[部署 · 资源与超时](deployment.md#资源与超时)）。
- **同一个会话在另一个页面打开**时，新页面接管，旧页面停止输入并提示，可以「另开独立会话」。
- **顶栏显示「输入未同步」**：远程页面没有接受页面模式里输入框的最新内容（鼠标悬停在状态上可看原因）。查看端会自动重发两次；在此期间回车不会发到远程页面，以免提交旧内容，点击照常可用。仍未恢复时，点回输入框再输入一个字符。
- **页面显示不对**时，先等同步完成，再试画面模式。

## 网页通知

网站的通知（例如 Claude 在任务完成时的提醒）显示在你自己的设备上，不在远程浏览器里。远程浏览器自己的通知和授权提示框始终关着，网站看到的通知权限就是你在工作台里的选择。

- 网站请求发通知时，页面右上方出现「Claude 想给你发通知」这样的提示（Claude 换成网站名），不挡住页面。点「允许」，本机浏览器第一次会再问一次是否允许工作台的通知，也要允许；点「拒绝」，网站看到被拒绝；点「×」（「以后再说」），网站看到还没决定，之后可以再问。
- 「⋯」菜单的「网页通知」可以整个「开启」或「关闭」，下面一行说明本机浏览器的状态，例如浏览器已阻止时要到浏览器的网站设置里允许工作台的通知。关闭后所有网站都看到通知被拒绝。设置和对各个网站的选择按浏览器配置保存在这台设备上，可以「清除」后重新选择。
- 点通知会切回工作台，并切到发出通知的标签页，网站也会收到这次点击。
- 只有打开着工作台的设备能收到通知：标签页切到后台没关系，关掉工作台页面后就收不到了，期间的通知不会补发。同时开着工作台的设备都会收到；只要其中一台允许了某个网站，网站就看到已允许，没允许的设备不显示。你正在看工作台时，网站一般认为自己在前台，不发通知；没有设备在看时，网站认为自己在后台。
- 网站在后台用 Service Worker 自己发出的通知（推送消息）收不到。

手机上的限制：

- **Android**：用 Chrome 打开工作台即可。切到别的应用后，系统可能在几分钟后暂停 Chrome 的这个页面，之后的通知要等你回到工作台才会恢复接收。
- **iPhone、iPad**：Safari 里的网页不能显示通知（iOS 16.4 起才支持，而且只限添加到主屏幕的网页应用）。在 Safari 里点分享按钮，选「添加到主屏幕」，之后从主屏幕的图标打开工作台，再在「网页通知」里开启。离开这个应用后，系统很快会暂停它，所以通知只在应用开着时可靠。
- 手机进入省电模式或锁屏后，通知可能延迟或收不到。

## 出口

出口是浏览器配置实际出网的 IP。每个配置必须绑定一个节点才能打开；网页、DNS 和 WebRTC 都经这个节点出去，同一配置的所有会话用同一个出口。

### 导入节点

在「网络与接入」→「代理来源」导入节点：节点链接、Mihomo YAML，或 HTTP/HTTPS 订阅地址。

- 你导入的「私有」来源只有你自己和管理员能用；「共享」来源由管理员维护，所有用户都能用。
- 订阅可以「刷新订阅」；「编辑」里可以替换订阅地址，留空则保留原地址。读取失败时保留原来的节点。订阅地址要能从公网访问，指向内网或本机的地址会被拒绝。
- 删除来源或其中的节点后，用到它的浏览器会话会关闭，CPA 授权失去出口，需要重新选择节点。不可用的节点不会被悄悄换成别的节点。

### 设置出口和检查出口

- 卡片的「⋯」→「设置出口」选择节点。已经绑定的配置改出口前会提示：频繁更换账号的出口 IP 可能触发平台风控。改出口会关闭这个配置在所有设备上打开的页面，之后按新出口启动。清除绑定后配置保留网站登录资料，但在重新选择节点前打不开。
- 「检查出口」显示实际出口 IP、地区、时区和检查时间。同时进行的检查有上限（见[部署 · 资源与超时](deployment.md#资源与超时)），超过时提示等当前检查完成后再试。配置正在运行时检查的是浏览器实际用的网络；没有运行时只检查绑定的节点，并标明「节点检查（配置尚未运行）」。同一个节点可能轮换 IP，所以节点检查不能代替运行中浏览器的检查。

## 当地时间

浏览器的时区跟随出口：打开配置时按出口 IP 的地理位置确定时区，网页、iframe 和 Worker 的时间都一致，夏令时自动处理。你设备所在的位置不参与。

顶栏的时钟显示出口所在城市和当地时间（城市未知时显示国家），悬停可以看到完整日期、时区和 UTC 偏移。时钟按服务器时间校准，你设备的时钟不准也不影响。

换出口会在下次打开时重新确定时区。「检查出口」发现时区和浏览器启动时不同时会提示：结束这个配置的所有会话，等「运行中」消失后再打开。

## 系统身份

系统身份决定网站看到的操作系统和设备特征，同一配置的所有会话用同一个身份。新建配置时选择，之后在卡片的「⋯」→「设置系统」修改：「Windows」或「Mac」；早先创建的配置可能显示「Linux（不推荐）」。修改会关闭这个配置在所有设备上打开的页面，下次连接按新身份启动；网站登录和出口保留。

只有部署者安装了 AliasMode 内核时才能选「Mac」，否则只有「Windows」。手机连接时只调整视口和触摸，不改变系统身份。

新建配置默认选「Mac」，也是推荐的身份。网站除了看浏览器报告的系统，还会看 TCP 连接本身的特征：TCP 连接是网络出口那台机器建立的，出口通常是 Linux 服务器，它的 TCP 特征（初始 TTL 64 等）和 Mac 一致，和 Windows（初始 TTL 128）不一致。所以出口不是一台 Windows 电脑时，选「Windows」更容易被检测网站识别出经过了代理；浏览器和系统身份都改变不了这一层。

## CPA

CPA 实例把 Claude 授权接成兼容 OpenAI 和 Anthropic 的 API，用调用 Key 访问。CPA 授权和浏览器里的网站登录互相独立：浏览器的 Cookie 不会变成 CPA 授权。

在「网络与接入」→「CPA 授权与 Key」：

1. 点「创建我的 CPA 实例」，再「启动实例」。每个用户最多一个私有实例；管理员维护的共享实例显示在同一页。
2. 「添加 Claude 授权」：选择授权使用的节点，默认是当前浏览器配置的出口。点「生成 Claude 授权链接」，在出口相同的远程浏览器里打开授权页；当前浏览器出口不同时，用「选择同出口浏览器」选一个已有配置或新建一个。远程浏览器会自动提交授权回调；也可以把完整的回调 URL 或授权码粘贴进来，点「提交授权回调」。添加授权期间，已有的授权继续可用。还没提交的回调会保留在当前标签页里，切换页签或刷新后仍在；提交、完成或「取消待完成授权」后清除。
3. 授权完成后，可以给每个凭据单独换节点、「停用凭据」「启用凭据」或「删除凭据」。凭据的节点和浏览器配置的出口互相独立。没有绑定节点的凭据不能启用。
4. 生成调用 Key：填写名称后点「生成」。完整的 Key 只显示这一次，关闭面板前先保存；之后列表里只显示前缀，可以随时「撤销」。共享实例的调用 Key 也由每个用户自己生成和撤销。

用调用 Key 访问（`rcpa_` 开头）：

| 用途                 | 地址                                                                  |
| -------------------- | --------------------------------------------------------------------- |
| OpenAI 兼容 Base URL | `https://browser.example.com/v1`                                      |
| Anthropic Messages   | `https://browser.example.com/v1/messages`，Bearer 或 `x-api-key` 认证 |
| 模型列表             | `GET https://browser.example.com/v1/models`                           |

工作台按 Key 找到对应的实例。调用 Key 只能调用，不能管理实例或凭据。

「检查出口」只检查凭据的节点能否联网和出口地址，不发起模型生成，也不能证明账号一定可用。实例启动后可以「打开原生管理页面」，查看实例配置、统计和诊断；私有实例只有本人能进入，共享实例只有管理员能进入。

停用你的用户会让你的调用 Key 失效并停止你的私有实例；删除用户会永久删除私有实例和你的全部调用 Key（见[管理](admin.md#停用和删除用户)）。

## 收件箱

部署者配置了 Resend 收件后，「收件箱」可以接收邮件，用于网站注册和验证：

- 「新建地址」：选择收件域名，地址名称可以不填（随机生成双词地址）。
- 「添加已有地址」：部署者启用了这项功能时，输入一个收件域名下的已有地址，用发到原邮箱的验证码绑定。
- 管理员也可以把地址分配给你。地址绑定或分配之后开始收录新邮件，只有你能读这些邮件。
- 自己新建和绑定的地址合计有上限，见[部署 · 资源与超时](deployment.md#资源与超时)；管理员分配的地址不受这个限制。到上限后先删除不再使用的地址。

在浏览器里注册或登录网站时，可以选用其中一个地址。

## remote-cc

[remote-cc](https://github.com/NotDesigned/remote-cc) 在服务器上运行 Claude Code，命令和文件留在你的电脑上。用某个浏览器配置启动时，它使用这个配置的 Claude 账号，全部网络流量经这个配置的节点出去，和网页版同一个出口。电脑上的命令见 remote-cc 的[连接 RCB](https://github.com/NotDesigned/remote-cc/blob/main/docs/usage.md#rcb)。

### 批准电脑

1. 在电脑上运行 `remote-cc rcb login https://browser.example.com`，终端显示一个连接码和一个链接。
2. 打开链接（没有登录时先登录），工作台打开「网络与接入」→「remote-cc」并填好连接码；也可以在「批准连接」里手动输入连接码。核对它和终端里的完全一致，点「查看」。
3. 页面显示请求来源的 IP、客户端和发起时间。确认是你自己刚刚运行的命令后点「批准」，否则点「拒绝」。

**批准就是让这台电脑以你的身份读取你的浏览器配置、使用你的节点。**只批准你自己刚刚发起、连接码完全一致的请求；别人发来的链接或连接码一律拒绝。

批准过的电脑列在「已连接的电脑」里，点「断开」立即让它失去访问。连接码的有效期和令牌的权限见[接口契约 · 批准流程](remote-cc.md#approval)。

### 登录 Claude Code

卡片的「⋯」→「在 remote-cc 中使用」显示这个配置的命令。第一次在电脑上运行 `remote-cc account login --rcb <配置>` 时：

1. 这个配置的浏览器里出现登录横幅，点「打开授权页」（浏览器没开时，下次打开这个配置时出现）。
2. 在新标签页里点「授权」，授权码会自动回到终端。

等待中的登录也列在「网络与接入」→「remote-cc」→「等待完成的 Claude Code 登录」里，可以在那里「在当前浏览器打开授权页」或「取消」。之后在项目目录里运行一次 `remote-cc rcb use <配置>`，以后只需 `remote-cc`。登录横幅的规则见[接口契约 · 登录横幅](remote-cc.md#login)。
